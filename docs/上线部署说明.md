# 上线部署说明

## 1. 先说明系统结构

这个项目不是只有 HTML 页面。它由三部分组成：

- 浏览器页面：`public/`
- Express 后端：`app.js` 和 `src/`
- MongoDB 数据库

如果只把 `public/` 上传到静态网站，页面能打开，但登录、问卷创建、填写和统计接口都不能用。
要发给所有人使用，需要同时部署后端和数据库。

## 2. 最快的临时公网演示

本机已经安装 Cloudflare Tunnel，可以先运行：

```powershell
cd survey-mongodb
npm start
```

再开一个终端：

```powershell
cloudflared tunnel --url http://localhost:3000
```

终端会输出一个类似下面的地址：

```text
https://xxxx.trycloudflare.com
```

这就是临时公网地址。问卷链接会自动变成：

```text
https://xxxx.trycloudflare.com/survey/campus26
```

注意：

- 电脑必须一直开机，`npm start` 和 `cloudflared` 两个窗口都要保持运行。
- 免费临时隧道没有可用性保证，重启后地址通常会变化。
- 数据库仍然在本机，关闭电脑后所有人都不能访问。

## 3. 长期部署到云平台

推荐组合：

- 应用：Render 或 Railway
- 数据库：MongoDB Atlas

MongoDB Atlas 步骤：

1. 注册 Atlas，创建一个免费集群。
2. 创建数据库用户，保存用户名和密码。
3. Network Access 允许云平台的出口 IP；课程演示可以临时允许 `0.0.0.0/0`。
4. 复制 Node.js 连接字符串，填入 `MONGODB_URI`。

Render 步骤：

1. 把项目上传到 GitHub。
2. 在 Render 新建 Web Service，选择这个仓库。
3. Build Command 填 `npm install`。
4. Start Command 填 `npm start`。
5. 环境变量至少设置：

```text
MONGODB_URI=mongodb+srv://用户名:密码@集群地址/
MONGODB_DB=survey_system
SESSION_SECRET=换成一串随机字符
```

6. 部署完成后，Render 会给一个 `https://...onrender.com` 地址。
7. 当前公网地址为 `https://livecam-reduced-calculators-stockholm.trycloudflare.com`。如果更换隧道或域名，
   把 `PUBLIC_ORIGIN` 设置为新的 `https://` 地址。

首次部署后可以运行一次演示数据脚本，或者直接注册新账号。

## 4. 链接生成规则

前端通过 `GET /api/app-info` 获取分享地址：

- 从公网隧道或云平台域名访问时，保留公网域名。
- 设置了 `PUBLIC_ORIGIN` 时，优先使用这个固定公网地址。
- 当前默认配置使用 `https://livecam-reduced-calculators-stockholm.trycloudflare.com`，其他网络可直接填写。

## 5. 上线前检查

- 修改演示账号密码，不要继续使用 `demo123`。
- 不要公开 MongoDB 的 27017 端口。
- 确认 `SESSION_SECRET` 不是默认值。
- 确认问卷的截止时间、匿名和重复填写设置。
- 用手机 4G/5G 网络实际打开一次登录页和问卷链接。
- 如果使用 Atlas，确认数据库网络访问规则没有限制云平台。
