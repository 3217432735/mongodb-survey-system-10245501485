# 测试用例

## 1. 测试环境

- 操作系统：Windows
- Node.js：v24.22.0
- MongoDB：6.0.19
- 测试框架：Node.js 自带 `node:test`
- 测试方式：启动真实的 Express 服务和真实的 MongoDB 测试数据库，通过 HTTP 接口测试

运行命令：

```powershell
cd survey-mongodb
npm test
```

测试数据库名会自动加上时间戳，跑完后删除，不影响演示数据。
